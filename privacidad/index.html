Política de Privacidad

Última actualización: 3 de septiembre de 2026.

Quiénes somos y alcance

Resúmenes Trials es un sitio editorial médico en español disponible en resumenestrials.com. Esta política explica el tratamiento asociado con la navegación, las cuentas, las comunicaciones, la publicidad y la operación interna del sitio. Para cualquier cuestión de privacidad puedes escribir a resumenestrials@outlook.com.

Datos que tratamos y para qué

  • Cuenta y perfil: nombre, apellido, nombre de usuario, correo electrónico, estado de confirmación, elección sobre el boletín, fechas técnicas de creación o actualización y datos necesarios para autenticar la cuenta. Se usan para crear y proteger el acceso, recuperar la contraseña y administrar el perfil.
  • Preferencias y biblioteca: áreas o intereses elegidos, preferencias de orden, identificadores de resúmenes marcados como favoritos o leídos y última visita. Se usan para ofrecer las funciones que la persona solicita dentro de su cuenta.
  • Seguridad: información de sesión, factores de autenticación en dos pasos y tokens de verificación anti-bot. Se usan para prevenir abuso y proteger el acceso. Las contraseñas y la autenticación se procesan en Supabase; no se guardan en los archivos públicos del sitio.
  • Comunicaciones: si escribes por correo o Telegram, tratamos los datos y el contenido que decidas incluir para responder. Si activas los avisos de nuevos resúmenes, usamos el correo y, cuando exista, el nombre para realizar esos envíos.
  • Datos técnicos: el alojamiento y los proveedores pueden procesar dirección IP, fecha y hora, navegador, dispositivo, ruta solicitada y señales de seguridad necesarias para entregar y proteger sus servicios. El sitio conserva además en el almacenamiento local del navegador hasta 40 errores técnicos recientes; antes de guardarlos sustituye correos y tokens detectables, y no los envía automáticamente a un servidor.

Cookies, almacenamiento local y publicidad

La navegación pública no exige una cuenta. Las funciones de autenticación pueden utilizar almacenamiento del navegador para mantener una sesión. Cloudflare Turnstile procesa la verificación técnica necesaria en formularios de acceso, registro o recuperación. Resúmenes Trials también utiliza Google AdSense; Google y sus socios pueden usar cookies, almacenamiento local u otros identificadores para servir, medir y proteger anuncios y, cuando corresponda, personalizarlos según la configuración regional y el consentimiento aplicable. Esto puede incluir dirección IP, características del dispositivo o navegador e interacciones con anuncios. Puedes consultar la Política de Privacidad de Google y administrar opciones publicitarias en Mi centro de anuncios.

Integración con Google Search Console

Resúmenes Trials usa una integración interna y privada para analizar el rendimiento orgánico de su propia propiedad, sc-domain:resumenestrials.com. La autorización solicita únicamente el alcance de solo lectura https://www.googleapis.com/auth/webmasters.readonly: acceso de lectura a los datos de Search Console de los sitios verificados que autorice el titular. No permite editar Search Console, modificar propiedades, eliminar datos ni cambiar su configuración.

La ejecución actual lee métricas agregadas de Search Analytics: fecha, consulta de búsqueda, página, clics, impresiones, CTR y posición media. El mismo alcance puede permitir datos por dispositivo o país e información técnica de indexación cuando la API correspondiente los devuelva y una función futura los solicite; el workflow actual no consulta esas dimensiones ni el estado de indexación. Esta integración no solicita nombre, correo, perfil ni otros datos de identidad de quienes visitan o buscan el sitio.

Los datos se usan únicamente para medir visibilidad orgánica; detectar oportunidades, pérdidas de rendimiento y posible canibalización; evaluar páginas y clusters; generar reportes internos; y mejorar arquitectura técnica, rastreo, indexación y enlazado interno. Toda recomendación permanece sujeta a revisión humana.

El identificador y secreto del cliente OAuth y el refresh token se guardan como secretos cifrados del repositorio. Los access tokens son temporales. La descarga detallada y los reportes derivados se procesan únicamente en el directorio temporal del runner, no se incorporan al sitio público, a los logs, al resumen de la ejecución ni a artefactos descargables, y se eliminan al finalizar el job. Cuando la entrega segura está disponible, el informe detallado se envía mediante Resend exclusivamente a la dirección administrativa autorizada; si no está disponible, el informe permanece efímero y no se publica. No vendemos estos datos, no los usamos para publicidad personalizada, perfiles de usuarios, evaluación crediticia, vigilancia ni decisiones clínicas, y no los transferimos a terceros salvo a los proveedores necesarios para ejecutar la automatización y efectuar esa entrega restringida.

El titular de la Cuenta de Google puede revocar el acceso desde las conexiones de su Cuenta de Google o solicitar que dejemos de usarlo por correo. Al retirarlo, los tokens dejan de permitir nuevas consultas. El uso de información recibida de las API de Google se limita a proporcionar y mejorar esta funcionalidad y se ajustará a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado cuando sean aplicables.

Proveedores

Utilizamos servicios de Supabase para autenticación, perfiles y preferencias; Resend para los avisos por correo elegidos por el usuario; GitHub para alojamiento y automatizaciones privadas; Google para AdSense, OAuth y Search Console; y Cloudflare Turnstile para verificación anti-bot. Cada proveedor trata la información necesaria para prestar su parte del servicio conforme a sus propias condiciones. No afirmamos que todos los datos permanezcan en un país concreto.

Conservación, seguridad y decisiones automatizadas

Los datos de cuenta se conservan mientras la cuenta permanezca activa o mientras sean necesarios para ofrecer y proteger el servicio. Las preferencias del boletín se conservan para respetar la elección vigente, incluida la baja. Los mensajes de contacto se conservan el tiempo necesario para atenderlos. Cuando no existe un plazo técnico fijo, revisamos la necesidad y limitamos el tratamiento a la finalidad indicada. Aplicamos conexiones HTTPS, acceso restringido, secretos fuera del código público, cifrado proporcionado por los proveedores, mínimo privilegio y controles de acceso por usuario. Ningún sistema garantiza seguridad absoluta.

No usamos los datos personales descritos aquí para tomar decisiones exclusivamente automatizadas que produzcan efectos jurídicos o equivalentes sobre una persona.

Opciones y solicitudes

Puedes actualizar el perfil, las preferencias y los avisos desde “Mi cuenta”; darte de baja desde el enlace incluido en cada correo; limpiar el registro técnico local desde las herramientas de diagnóstico del navegador; o pedir acceso, corrección, eliminación, limitación u oposición escribiendo a resumenestrials@outlook.com. Para proteger la cuenta podremos pedir información razonable que permita verificar la solicitud. Algunas obligaciones técnicas, de seguridad o de conservación legítima pueden limitar una eliminación inmediata.

Cambios

Podemos actualizar esta política si cambian las funciones o proveedores. Publicaremos la versión vigente en esta misma URL e indicaremos su fecha de actualización. Los Términos y condiciones complementan esta información.
