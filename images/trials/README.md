# Imágenes editoriales de trials

Estas imágenes se generan automáticamente a partir de datos propios de `resumenes.json`.
No reproducen figuras, tablas, fotografías, logotipos de revistas ni material gráfico de terceros.
Usan únicamente composición geométrica original, la marca Resúmenes Trials y texto factual del ensayo con fines descriptivos.
