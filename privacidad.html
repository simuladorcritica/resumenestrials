Aviso de privacidad

Última actualización: 20 de agosto de 2026

Responsable y contacto

Resumenes Trials es responsable del tratamiento de los datos personales recabados mediante las funciones de cuenta de este sitio. Para solicitudes relacionadas con privacidad, datos personales o derechos ARCO, el medio de contacto habilitado es resumenestrials@outlook.com.

Datos que tratamos

Cuando creas una cuenta podemos tratar nombre, apellido, nombre de usuario, correo electrónico, identificadores internos de autenticación, fechas asociadas a la cuenta y tu preferencia de recibir o no avisos por correo. Los proveedores técnicos pueden generar registros de seguridad y conexión indispensables para operar el servicio.

No solicitamos datos clínicos, expedientes médicos ni otros datos sensibles para crear una cuenta. No debes introducir información médica de pacientes en los campos de registro o perfil.

Finalidades primarias

  • Crear, identificar y administrar tu cuenta.
  • Autenticar el acceso, confirmar el correo y recuperar la contraseña.
  • Proteger la seguridad del servicio y prevenir uso indebido.
  • Guardar las preferencias asociadas a tu perfil.

Finalidad opcional de comunicaciones

El envío de avisos sobre nuevos resúmenes es opcional y se realiza únicamente cuando marcas la casilla correspondiente. Puedes retirar ese consentimiento desde tu cuenta o mediante el enlace de baja incluido en los correos, sin perder el acceso a tu cuenta.

Proveedores tecnológicos

La autenticación y la base de datos de perfiles se gestionan mediante Supabase. El sitio se publica mediante infraestructura de GitHub. Cuando aceptas recibir avisos de nuevos resúmenes, el envío de esos mensajes se procesa mediante Resend, proveedor de infraestructura de correo electrónico. Para efectuar el envío, Resend recibe la información estrictamente necesaria, como la dirección de correo del destinatario y el contenido del mensaje. Estos proveedores pueden procesar información técnica en los países donde operan sus servicios, conforme a sus propias condiciones y medidas de seguridad.

Contraseñas y seguridad

Resumenes Trials no almacena contraseñas en los archivos públicos ni en el repositorio del sitio. Las credenciales son gestionadas por el sistema de autenticación. La base de perfiles utiliza controles de acceso para que cada usuario autenticado consulte y modifique únicamente su propio perfil. Si activas la verificación en dos pasos, el segundo factor se gestiona mediante el sistema de autenticación y no se almacena en los archivos públicos del sitio.

Conservación

Los datos se conservarán mientras la cuenta permanezca activa o mientras sean necesarios para las finalidades descritas. Si solicitas la cancelación de la cuenta, se eliminarán o bloquearán los datos cuando corresponda, salvo aquellos que deban conservarse temporalmente por razones de seguridad, cumplimiento u otras obligaciones aplicables.

Derechos ARCO y revocación

Puedes solicitar acceso, rectificación, cancelación u oposición respecto de tus datos personales, así como revocar el consentimiento para comunicaciones. Envía un correo con el asunto “Derechos ARCO” indicando el correo asociado a tu cuenta, el derecho que deseas ejercer y la información necesaria para localizar tu registro. Podremos solicitar información razonable para verificar que la solicitud corresponde a la persona titular.

Limitación del uso

Puedes limitar el envío de comunicaciones desactivando la preferencia de avisos desde tu cuenta o usando el enlace de baja incluido en cada mensaje. La desactivación no afecta los correos estrictamente necesarios para autenticación, seguridad o recuperación de acceso.

Cookies y navegación pública

La navegación pública no requiere una cuenta ni utiliza cookies de publicidad. El sistema de autenticación puede utilizar almacenamiento local u otros mecanismos técnicos indispensables para mantener una sesión iniciada.

Cambios al aviso

Las modificaciones relevantes a este aviso se publicarán en esta misma página. Si un cambio modifica de forma sustancial las finalidades del tratamiento, se solicitará el consentimiento cuando resulte necesario.

Marco aplicable

El tratamiento de datos se realizará conforme al marco mexicano aplicable a la protección de datos personales en posesión de particulares. Este aviso describe el funcionamiento actual del sitio y podrá actualizarse si se incorporan nuevas funciones o proveedores.
